## **Project Overview**

This project showcases an end-to-end HR analytics solution using **Power BI**, **Tableau**, **SQL**, and **Excel**. It is designed to help HR teams track workforce metrics, uncover attrition trends, and support strategic planning.

---

### **Dataset**
Open-source 2022 HR dataset from a medical components manufacturing company, containing employee records, attrition, job roles, education, and demographics.

---

### **Objective**
- Track core HR metrics with clearly defined KPIs.
- Understand attrition and workforce trends.
- Provide insights to improve retention and workforce planning.

---

### **Key KPIs & Insights**

- **Employee Count & Active Workforce:** Monitor headcount and productivity capacity.
- **Attrition Count & Rate:** Identify turnover levels and benchmark against industry standards.
- **Average Age:** Assess workforce demographics and succession planning needs.
- **Attrition by Gender & Age:** Visualize disparities and inform targeted strategies.
- **Department-wise Attrition:** Spot internal hotspots and address organizational issues.
- **Education Field Analysis:** Understand attrition patterns by education background.
- **Job Satisfaction Trends:** Evaluate engagement levels to improve workplace culture.

---

### **Project Components**

**🔹 Power BI:**  
Built an interactive dashboard highlighting HR KPIs, attrition trends, and workforce breakdowns.

**🔹 Tableau:**  
Developed custom charts and calculated fields for deep-dive trend analysis and department segmentation.

**🔹 SQL:**  
Queried and validated key metrics; created SQL test documents for Tableau and Power BI integrations.

**🔹 Excel:**  
Designed an Excel-based dashboard using pivot tables and charts for quick offline insights.

---

### **Conclusion**

This project demonstrates the ability to translate raw HR data into actionable insights using modern BI tools. It reflects strong skills in data storytelling, metric design, and cross-functional reporting — key for Business Intelligence and Data Analyst roles.
